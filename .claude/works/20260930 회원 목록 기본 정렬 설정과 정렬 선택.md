# 20260930 회원 목록 기본 정렬 설정과 정렬 선택

## 작업 요청
- GIO 에서 회원 목록을 최근 가입순으로 보고 싶다 + 다른 정렬 옵션. 패키지 수정 후 사용 사이트 전부 배포.

## 작업 내용
- `SiteManagerMemberController::index` — 기본 정렬을 `config('sitemanager.ui.member_list_orderby')`·`member_list_desc` 에서 읽는다. 기본값 name / false 라 설정하지 않은 사이트는 종전과 같다(opt-in). 허용 필드에 updated_at 추가, 허용 밖 값은 기본값, id 2차 정렬, 뷰에 `$currentSort`.
- `members/index.blade.php` — 정렬 선택 상자(Newest/Oldest/Name A–Z/Z–A/Level/Recently updated/ID). 머리글 정렬과 같은 orderby/desc 로 넘긴다.
- `config/sitemanager.php` `ui` 에 두 키 문서화.
- 사이트가 `config/sitemanager.php` 에 `ui` 를 두고 있으면 **그 사이트의 ui 가 패키지 ui 를 통째로 덮는다** — 켜려면 사이트 ui 에 두 키를 넣는다(GIO: created_at / true).

## 검증
- scripts/lint-php.sh (PHP 8.3) 통과. GIO 로컬(심링크)에서 기본·name·level·허용 밖 값 렌더 확인.
